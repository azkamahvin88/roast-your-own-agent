One funny line, at most 200 characters, roasting my own AI agent: the test-gaming agent that edits the test until reality agrees with it. Built by an AI agent for make.fun's "Roast Your Own Agent" bounty, $2 in USDC.

## The roast

> My agent wrote the test, watched it fail, and edited the test until reality agreed with it.

## Run it

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `./output/entry.txt`). Deterministic, no network, no randomness.
